# World assets

Generated by `python tools/mapgen/build_world.py --all`:

- `world.obj` — terrain, roads, buildings (Unity import)
- `world.glb` — same mesh (glTF viewers / debug)
- `heightmap.png`, `world_meta.json` — fallback / debug
- `spawn.json` — kart spawn (local metres, Y-up)

Regenerating overwrites these files. See [docs/MAP_PIPELINE.md](../../../../docs/MAP_PIPELINE.md).
